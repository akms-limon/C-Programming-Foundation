# C Programming Foundation

The repository represents my **beginner-stage programming practice and the early part of my programming journey**.

My personal collection of **C programming fundamentals, practice programs, and learning exercises**.

This repository contains the programs I wrote while learning the basics of C programming and building a foundation for problem solving and programming.

## Learning Source

Most of the concepts and practice programs in this repository were learned from **Tamim Shahriar Shubhin's C programming books**.

These books played an important role in the **beginner stage of my programming journey** and helped me build my programming fundamentals from the ground up.

They were a major part of my **early programming journey in life**, and I genuinely recommend these books to anyone who is starting their programming journey from the beginning.
